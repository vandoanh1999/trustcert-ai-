## 2026-04-07 - [Human-Friendly Expert Aliases & Interaction Delight]
**Learning:** Mapping technical internal identifiers (like file paths) to human-readable aliases with emojis significantly lowers the cognitive load for non-technical users. Using ephemeral feedback mechanisms like `st.toast` instead of static success blocks keeps the user in their flow without requiring them to scroll or manually dismiss alerts.
**Action:** Always provide a mapping layer between backend technical keys and frontend display names. Prioritize non-intrusive feedback for routine actions.
