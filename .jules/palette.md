## 2025-04-12 - [Improved Genesis Hub Interaction]
**Learning:** Transitioning from technical file paths to friendly aliases (expert names) in multiselect widgets significantly improves non-technical user orientation. Additionally, industry-standard star-based feedback (st.feedback) is more intuitive than linear sliders for rating qualitative AI responses.
**Action:** Always map backend technical identifiers to user-friendly aliases in the UI layer and use st.feedback for rating interactions in Streamlit 1.35+.
