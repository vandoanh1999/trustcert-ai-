## 2025-05-15 - [Friendly Expert Aliases]
**Learning:** Hiding technical implementation details, such as file paths for model adapters, behind intuitive, emoji-enhanced aliases (e.g., "🧠 Reasoning") significantly improves the user's mental model of the system and reduces cognitive load for non-technical users.
**Action:** Always map technical resource identifiers (paths, IDs, hashes) to human-readable labels in the frontend to maintain a clean and accessible user interface.
