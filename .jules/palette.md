# Palette UX Journal - Genesis Core

## 2026-04-14 - Friendly Names & Enhanced Guidance
**Learning:** In technical AI platforms, exposing raw file paths or internal IDs to end-users (e.g., in expert selection) creates a significant cognitive barrier and makes the interface feel "unfinished."
**Action:** Always implement a friendly name mapping for internal entities and use high-level tooltips to explain technical interactions.
