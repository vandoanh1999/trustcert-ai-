## 2025-05-15 - [Expert Alias Mapping]
**Learning:** Mapping technical internal paths (like expert model filepaths) to human-readable aliases in the UI significantly reduces cognitive load for non-technical users and makes the system feel more approachable.
**Action:** Always use a mapping layer between backend identifiers and frontend display labels for user-facing selection components.

## 2025-05-15 - [Dynamic Sentiment Feedback & Input Cues]
**Learning:** Mapping abstract numerical ratings (0.0-1.0) to familiar emotional cues (emojis and labels) in real-time significantly enhances user engagement and makes system feedback feel more human. Additionally, proactive input guidance (tooltips/placeholders) and live state feedback (character counters) reduce user uncertainty during interactions.
**Action:** Use dynamic status labels for range-based inputs to provide immediate context, and always include proactive guidance and live counters for text-heavy inputs.
