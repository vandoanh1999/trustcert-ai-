## 2025-05-15 - [Expert Alias Mapping]
**Learning:** Mapping technical internal paths (like expert model filepaths) to human-readable aliases in the UI significantly reduces cognitive load for non-technical users and makes the system feel more approachable.
**Action:** Always use a mapping layer between backend identifiers and frontend display labels for user-facing selection components.

## 2026-06-01 - [Multi-layered Guidance and Thematic Feedback]
**Learning:** Combining `help` tooltips, `placeholder` text, and primary button styling provides multi-layered guidance that clarifies intent and hierarchy. Using thematic avatars (like '🌌') in chat-style response blocks further humanizes the technical output.
**Action:** Apply a consistent set of tooltips, placeholders, and primary CTAs to main interaction points, and wrap AI outputs in persona-aligned chat containers.
