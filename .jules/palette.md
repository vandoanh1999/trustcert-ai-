## 2025-05-15 - [Expert Alias Mapping]
**Learning:** Mapping technical internal paths (like expert model filepaths) to human-readable aliases in the UI significantly reduces cognitive load for non-technical users and makes the system feel more approachable.
**Action:** Always use a mapping layer between backend identifiers and frontend display labels for user-facing selection components.

**Learning:** Using `st.chat_message` instead of generic `st.code` blocks for AI responses creates a more immersive and intuitive conversational experience. It aligns user expectations with modern chat interfaces and removes the need for technical labels like "(Click to copy)".
**Action:** Default to conversational components for AI-generated prose to improve visual flow and accessibility.
